# 🎨 Personalização de Template Bootstrap

## 📌 Sobre o projeto

Projeto desenvolvido a partir da clonagem de um template Bootstrap, com o objetivo de personalizar seu design, adaptar os componentes visuais e modificar a estrutura original para criar uma nova identidade visual.

O projeto demonstra a prática de desenvolvimento front-end, explorando layouts responsivos, componentes reutilizáveis e customização de estilos.

## ✨ Funcionalidades

- 🎨 Personalização do layout original.
- 🧩 Modificação de componentes e elementos visuais.
- 📱 Adaptação para dispositivos móveis e desktops.
- 🖌️ Customização de cores, tipografia e espaçamentos.
- 🧱 Reutilização de componentes do Bootstrap.

## 🎯 Objetivo

Praticar habilidades de desenvolvimento front-end por meio da análise, clonagem e personalização de templates existentes, explorando técnicas de estilização e adaptação de interfaces web.

## ▶️ Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
